RIP Overview

Routing Information Protocol (RIP) is an older, purely Distance-Vector protocol. While rarely used in modern large enterprises, its concepts are fundamental.

Key Characteristics

  • Metric: Hop Count (Maximum is 15. 16 is considered infinite/unreachable).
  • AD: 120
  • Updates: Broadcasts/Multicasts entire routing table every 30 seconds.
  • Algorithm: Bellman-Ford.

RIPv1 vs RIPv2

  • RIPv1: Classful (does not send subnet masks in updates). Uses broadcast (255.255.255.255). No authentication.
  • RIPv2: Classless (sends subnet masks). Uses multicast (224.0.0.9). Supports authentication.

EIGRP Overview

Enhanced Interior Gateway Routing Protocol (EIGRP) is a Cisco-proprietary "Advanced Distance-Vector" protocol. It features blazing-fast convergence thanks to its backup route mechanism.

Core Mechanics

  • Metric: Bandwidth + Delay (by default).
  • AD: 90 (Internal), 170 (External).
  • Algorithm: DUAL (Diffusing Update Algorithm).
  • Uses Multicast 224.0.0.10 for updates.
  • Requires matching Autonomous System (AS) numbers to form neighborships.

The 3 EIGRP Tables

  • Neighbor Table: Lists all directly connected EIGRP routers.
  • Topology Table: The "map". Contains all routes learned from neighbors, including backups.
  • Routing Table: The absolute best paths chosen from the Topology Table.

🧠 EIGRP Terminology (Crucial for Exam)

Successor

The best route to a destination network. This route is injected into the routing table.

Feasible Successor

A valid, loop-free backup route. Kept in the Topology Table. If the Successor fails, EIGRP instantly switches to this route without recalculating.

Feasible Distance (FD)

The total metric cost for the local router to reach the destination network.

Reported Distance (RD)

Also called Advertised Distance. The metric cost for a neighbor router to reach the destination network.

Configuration Syntax

RIPv2 Configuration

R1(config)# router rip R1(config-router)# version 2 R1(config-router)# no auto-summary ! Network commands in RIP are always classful, even in v2. R1(config-router)# network 10.0.0.0

EIGRP Configuration

! '100' is the AS number. Must match! R1(config)# router eigrp 100 R1(config-router)# no auto-summary ! EIGRP allows wildcard masks for precision. R1(config-router)# network 10.1.1.0 0.0.0.255

⌨️ Verification

show ip route Routing table. RIP routes marked with R. EIGRP routes marked with D (for DUAL).
show ip eigrp neighbors Displays active EIGRP adjacencies. If a neighbor isn't here, routing won't work.
show ip eigrp topology Shows Successors and Feasible Successors.

⚡ Quick Quiz (Active Recall)

Click questions to reveal answers.

1. What is the name of the algorithm used by EIGRP to calculate paths and guarantee loop-free routing? ▼
DUAL (Diffusing Update Algorithm).
2. In RIP, what metric value indicates that a network is unreachable (infinite)? ▼
A hop count of 16. (15 is the maximum valid hop count).
3. Which EIGRP table stores backup routes (Feasible Successors) that are not currently in use? ▼
The Topology Table. Only the primary best route (Successor) makes it into the actual Routing Table.
4. When looking at 'show ip route', what letter code designates an EIGRP learned route? ▼
D (stands for DUAL). O is for OSPF, R is for RIP, and E is for EGP/Exterior protocols.
