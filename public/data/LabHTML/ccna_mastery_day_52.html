STP & FHRP Sync

STP & FHRP Synchronization

In modern networks, Spanning Tree Protocol (Layer 2) and First Hop Redundancy Protocols like HSRP (Layer 3) must be configured to agree with each other. Learn how to align their active roles to prevent suboptimal routing and enable load balancing.

🧠 The Synchronization Problem

Why Align L2 and L3?

  • The Layer 2 Path (STP) Access switches forward traffic toward the STP Root Bridge. If an access switch has redundant uplinks, it blocks all paths except the one leading directly to the Root Bridge.
  • The Layer 3 Path (HSRP) End hosts send inter-subnet traffic to their Default Gateway. In an FHRP setup, this is the Virtual IP (VIP) hosted by the HSRP Active router.
  • The Suboptimal Result If DSW1 is the HSRP Active router, but DSW2 is the STP Root Bridge, the access switch will send traffic to DSW2 first. DSW2 must then forward it across the inter-switch trunk link to DSW1 to be routed. This adds unnecessary hops, latency, and consumes trunk bandwidth.

The Load Balancing Solution

To utilize all your expensive hardware, you divide your network. For VLAN 10, make DSW1 both the STP Root and the HSRP Active router. For VLAN 20, make DSW2 both the STP Root and HSRP Active router. This achieves perfect alignment and efficient load sharing.

Impact of Misalignment

Switch Hops to reach the active Gateway.

Misalignment forces traffic across the Distribution switch interconnect link, effectively doubling the Layer 2 path length.

💻 Device Configuration Lab

Review the commands to perfectly align STP Root Bridges with HSRP Active routers across multiple VLANs.

Goal: Make DSW1 the Primary Root and Active Gateway for VLAN 10, and the Secondary backup for VLAN 20.

DSW1> enable
DSW1# configure terminal

! --- LAYER 2: SPANNING TREE ALIGNMENT ---
! Set as Primary Root for VLAN 10 (Drops priority to 24576)
DSW1(config)# spanning-tree vlan 10 root primary
! Set as Secondary Root for VLAN 20 (Drops priority to 28672)
DSW1(config)# spanning-tree vlan 20 root secondary

! --- LAYER 3: HSRP ALIGNMENT ---
! Configure SVI 10
DSW1(config)# interface vlan 10
DSW1(config-if)# ip address 10.0.10.252 255.255.255.0
! HSRP Configuration for VLAN 10 (Make it Active)
DSW1(config-if)# standby 10 ip 10.0.10.254
DSW1(config-if)# standby 10 priority 110
DSW1(config-if)# standby 10 preempt
DSW1(config-if)# exit

! Configure SVI 20
DSW1(config)# interface vlan 20
DSW1(config-if)# ip address 10.0.20.252 255.255.255.0
! HSRP Configuration for VLAN 20 (Leave priority at default 100 to be Standby)
DSW1(config-if)# standby 20 ip 10.0.20.254
DSW1(config-if)# standby 20 preempt

Goal: The exact opposite of DSW1. Make DSW2 the Primary Root and Active Gateway for VLAN 20, and the Secondary backup for VLAN 10. This achieves perfect Load Balancing.

DSW2> enable
DSW2# configure terminal

! --- LAYER 2: SPANNING TREE ALIGNMENT ---
! Set as Secondary Root for VLAN 10
DSW2(config)# spanning-tree vlan 10 root secondary
! Set as Primary Root for VLAN 20
DSW2(config)# spanning-tree vlan 20 root primary

! --- LAYER 3: HSRP ALIGNMENT ---
! Configure SVI 10
DSW2(config)# interface vlan 10
DSW2(config-if)# ip address 10.0.10.253 255.255.255.0
! HSRP Configuration for VLAN 10 (Leave priority at default 100 to be Standby)
DSW2(config-if)# standby 10 ip 10.0.10.254
DSW2(config-if)# standby 10 preempt
DSW2(config-if)# exit

! Configure SVI 20
DSW2(config)# interface vlan 20
DSW2(config-if)# ip address 10.0.20.253 255.255.255.0
! HSRP Configuration for VLAN 20 (Make it Active)
DSW2(config-if)# standby 20 ip 10.0.20.254
DSW2(config-if)# standby 20 priority 110
DSW2(config-if)# standby 20 preempt

📝 Lab Tasks & Solutions

Check off the steps as you complete them to save your progress.

DSW1# show spanning-tree vlan 10
! Look for "This bridge is the root" or check which ports are Root Ports vs Designated.

DSW1# show standby brief
! Look at the State column to see if it is Active or Standby.

Result (Pre-Config): DSW2 is the STP Root (due to a lower MAC address, since priorities are default 32768). However, DSW1 is the HSRP Active router. They are unsynced.

Configure DSW1 to take over both roles.

DSW1(config)# spanning-tree vlan 10 root primary
DSW1(config)# interface vlan 10
DSW1(config-if)# standby 10 priority 110
DSW1(config-if)# standby 10 preempt

Don't forget to configure DSW2 as the STP secondary root for VLAN 10 as a backup!

Configure DSW2 to balance the load by taking over VLAN 20.

DSW2(config)# spanning-tree vlan 20 root primary
DSW2(config)# interface vlan 20
DSW2(config-if)# standby 20 priority 110
DSW2(config-if)# standby 20 preempt

Likewise, configure DSW1 as the STP secondary root for VLAN 20.

Before the configuration, traceroute went through DSW2's IP before hitting the Core. Now:

C:\> tracert 8.8.8.8
Tracing route to 8.8.8.8 over a maximum of 30 hops:
1 1 ms 1 ms 1 ms 10.0.10.252 (DSW1 SVI)
2 2 ms 1 ms 2 ms 10.0.1.2 (Core Router)
3 3 ms 2 ms 3 ms 8.8.8.8 (Destination)

Because DSW1 is the STP Root, ASW1's port to DSW1 is Forwarding. Traffic flows directly to DSW1, which routes it immediately to the Core. No trunk hopping required!

📋 Command Reference

🔍
Command Mode Purpose
spanning-tree vlan [x] root primary Global Config Forces the switch to become the STP Root Bridge for a specific VLAN (usually drops priority to 24576).
spanning-tree vlan [x] root secondary Global Config Sets the switch as the backup STP Root Bridge (usually drops priority to 28672).
standby [grp] priority [num] Interface Config Sets HSRP election priority. Set > 100 to make the router the Active gateway.
standby [grp] preempt Interface Config Crucial: Allows the router to reclaim the HSRP Active role if it reboots and comes back online.
show spanning-tree vlan [x] Privileged EXEC Verifies if "This bridge is the root" for the specific VLAN.
show standby brief Privileged EXEC Verifies if the router is Active or Standby for its configured HSRP groups.
